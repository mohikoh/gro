Вимоги та обмеження нанесення гравіювання

Для якісного виконання лазерного гравіювання та збереження функціональності вашого пристрою ми встановлюємо певні вимоги. Це допомагає нам гарантувати відмінний результат та уникнути пошкоджень техніки.

  • Пристрій має бути в робочому стані
  • Поверхня для гравіювання повинна бути чистою та без пошкоджень.
  • Для клавіатур - всі клавіші повинні бути на місці та функціонувати.
  • Не всі види пластику підходять для гравіювання.
  • Деякі покриття можуть бути пошкоджені лазером.
  • Пристрої з тріщинами або сколами не беруться до роботи.
  • Векторні формати (AI, EPS, SVG) – переважно.
  • Растрові зображення високої роздільної здатності (мінімум 300 DPI).
  • Підтримувані формати: PNG, JPG, PDF, CDR.
  • Пристрої з активною гарантією виробника (за бажанням клієнта).
  • Мокрі або пошкоджені пристрої.
  • Зображення, що порушують авторські права.
  • Непристойний або образливий контент.
